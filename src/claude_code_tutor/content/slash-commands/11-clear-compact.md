# `/clear` & `/compact`

Two ways to manage the conversation, with very different effects:

## `/clear`

Starts fresh — it drops the conversation history so the next turn begins with a
clean context. Reach for it when you switch to an unrelated task and don't want
the old discussion influencing (or crowding) the new one.

## `/compact`

Summarises the conversation so far into a compact form, freeing up context space
while **retaining the gist** of what happened. Use it on a long session that's
filling the context window but where you still need continuity.

Rule of thumb: **`/clear` when the past is irrelevant, `/compact` when it's
relevant but bulky.**
