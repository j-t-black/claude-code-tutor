# Account, environment & integrations

The setup-and-surface commands you touch occasionally:

- **`/login`** · **`/logout`** — sign in and out of your Anthropic account.
- **`/terminal-setup`** — configure terminal keybindings (e.g. Shift+Enter for
  newlines). **`/keybindings`** — open the keybindings config file.
- **`/ide`** — manage IDE integrations (VS Code, JetBrains). **`/desktop`** (`/app`)
  · **`/chrome`** — continue in the desktop app or configure the Chrome integration.
- **`/teleport`** (`/tp`) · **`/remote-control`** (`/rc`) — pull a Claude-on-the-web
  session into this terminal, or expose this session for control from claude.ai.
- **`/setup-bedrock`** · **`/setup-vertex`** — point Claude Code at Amazon Bedrock
  or Google Vertex AI instead of the default API.

Most you set once and forget; good to know they exist.
