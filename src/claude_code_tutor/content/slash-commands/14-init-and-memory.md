# Setting up project knowledge

- **`/init`** — scan the repo and generate a starter `CLAUDE.md` with build
  commands and conventions. The first thing to run in a new project so Claude
  knows how to build, test, and move around.
- **`/memory`** — view and edit every memory source: the `CLAUDE.md` hierarchy,
  imported rules, and the auto-memory Claude maintains for itself.

These are the front door to the **Memory** pillar in the Advanced tier — start
here, go deep there.
