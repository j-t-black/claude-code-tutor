# `/help`

`/help` lists the slash commands available in your current session, along with a
short description of each. Because the available commands depend on your setup
(plugins, custom commands, MCP servers all add their own), `/help` is the
authoritative, *live* list for **your** environment — more reliable than any
static cheatsheet.

Use it whenever you're unsure what's installed, or to discover commands you
haven't tried. It's the natural first stop, and a good habit after installing a
new plugin or skill.
