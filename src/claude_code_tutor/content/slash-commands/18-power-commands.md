# Gateways to the powerful stuff

These commands are the front doors to deeper features — each has a full lesson in
the **Advanced** or **Workflows** tier:

- **`/agents`** — create and manage subagents → *Advanced: Subagents*.
- **`/mcp`** — connect external tools → *Advanced: MCP servers*.
- **`/hooks`** — view lifecycle automations → *Advanced: Hooks*.
- **`/permissions`** (alias `/allowed-tools`) · **`/add-dir <path>`** — manage tool
  access and grant extra directories for the session.
- **`/skills`** — list skills (press `t` to sort by token cost) → *Advanced: Skills*.
- **`/background`** (`/bg`) · **`/tasks`** · **`/batch`** · **`/goal`** — run work
  detached, in parallel, or until a condition is met → *Workflows*.
- **`/schedule`** (`/routines`) · **`/loop`** — recurring agents → *Workflows: Scheduling*.

Skim these now; the depth is one tier over.
