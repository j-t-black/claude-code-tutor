# `/context`

`/context` shows how your context window is currently being spent — a breakdown
of what's consuming tokens (system prompt, tools, files, conversation, memory,
and so on).

It's the diagnostic you run when a session feels sluggish or you're approaching
the window limit: see *what* is taking up room, then decide whether to `/compact`,
`/clear`, drop some file references, or trim tool/MCP overhead. You can't manage
what you can't see — this is how you see it.
