# /teleport

`/teleport` (alias `/tp`) pulls a Claude Code *on the web* session down into this terminal, so you can keep going locally. Its mirror image is [/remote-control](lesson:ref-remote-control); the desktop equivalent is [/desktop](lesson:ref-desktop).
