# /code-review

`/code-review [target]` reviews your current diff for correctness bugs; lower effort biases toward higher-confidence findings, and `--comment` can post them as PR comments. Run it before you commit. For a security-specific pass use [/security-review](lesson:ref-security-review); to eyeball the diff first, [/diff](lesson:ref-diff).
