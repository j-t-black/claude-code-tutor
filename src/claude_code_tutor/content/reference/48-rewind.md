# /rewind

`/rewind` rolls **code and conversation** back to an earlier checkpoint (or
summarises from a chosen message) — the undo button for a turn that went sideways.
Where [/branch](lesson:ref-branch) forks forward into a new line, rewind steps
backward in the current one. Pair it with [/resume](lesson:ref-resume) to hop
between saved states.

**Related:** [/branch](lesson:ref-branch) · [/resume](lesson:ref-resume) · [/plan](lesson:ref-plan)
