# /add-dir

`/add-dir <path>` grants Claude file access to an additional directory for this session — useful when your work spans repos or a sibling folder. It's a scoped companion to the broader rules in [/permissions](lesson:ref-permissions).

**Related:** [/permissions](lesson:ref-permissions)
