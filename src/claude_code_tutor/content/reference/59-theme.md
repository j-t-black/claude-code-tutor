# /theme

`/theme` switches the colour theme (light, dark, colourblind-friendly, or custom). Cosmetic, but a comfortable theme matters over long sessions. It's also reachable from [/config](lesson:ref-config); for the renderer itself, [/tui](lesson:ref-tui).

**Related:** [/config](lesson:ref-config) · [/tui](lesson:ref-tui)
