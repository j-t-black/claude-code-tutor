# /clear

`/clear` starts a fresh conversation, dropping the history (project memory /
CLAUDE.md is kept). Use it when you switch to an unrelated task and don't want the
old discussion crowding or biasing the new one. The distinction worth
internalising: [/compact](lesson:ref-compact) when the past is relevant but bulky,
`/clear` when it's simply irrelevant. To pick an old thread back up instead of
dropping it, see [/resume](lesson:ref-resume).

**Related:** [/compact](lesson:ref-compact) · [/resume](lesson:ref-resume)
