# /permissions

`/permissions` (alias `/allowed-tools`) manages your allow / ask / deny rules for tool access — exactly what we used to make this build autonomous. To widen access by folder for a session, [/add-dir](lesson:ref-add-dir); to see active automation, [/hooks](lesson:ref-hooks).
