# /agents

`/agents` manages your subagents — the specialised, separate-context assistants
you delegate to (defined as markdown files in `.claude/agents/`). Delegating heavy
exploration to one keeps your main [/context](lesson:ref-context) clean, which is
the main reason to reach for them. The Advanced → Subagents lesson goes deep and
exports a working example you can keep.

**Related:** [/context](lesson:ref-context)
