# /mobile

`/mobile` (aliases `/ios`, `/android`) shows a QR code to download the Claude mobile app, so you can carry a session in your pocket — pairs with [/remote-control](lesson:ref-remote-control). For background tunes, [/radio](lesson:ref-radio).
