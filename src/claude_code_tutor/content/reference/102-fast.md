# /fast

`/fast` toggles **fast mode** — quicker output on supported Opus models *without*
dropping to a smaller model. Reach for it when you want snappier turns on routine
work. It pairs with [/model](lesson:ref-model) and [/effort](lesson:ref-effort)
for tuning the speed / depth / cost balance.

**Related:** [/model](lesson:ref-model) · [/effort](lesson:ref-effort)
