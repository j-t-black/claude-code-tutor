# /stop

`/stop` ends the current background session — the counterpart to
[/background](lesson:ref-background). When you're done with detached work, `/stop`
shuts it down; [/tasks](lesson:ref-tasks) shows what's still running.

**Related:** [/background](lesson:ref-background) · [/tasks](lesson:ref-tasks)
