# /feedback

`/feedback` (aliases `/bug`, `/share`) submits a bug report or feature request with your session context attached, so the team can see what happened. For what changed recently, [/release-notes](lesson:ref-release-notes); to reproduce first, [/debug](lesson:ref-debug).

**Related:** [/debug](lesson:ref-debug) · [/release-notes](lesson:ref-release-notes)
