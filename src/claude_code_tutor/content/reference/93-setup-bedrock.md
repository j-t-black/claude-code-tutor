# /setup-bedrock

`/setup-bedrock` configures Claude Code to authenticate against **Amazon Bedrock** and use its models instead of the default API — common in AWS-centric orgs. The Google equivalent is [/setup-vertex](lesson:ref-setup-vertex); both change what [/login](lesson:ref-login) means.

**Related:** [/setup-vertex](lesson:ref-setup-vertex) · [/login](lesson:ref-login)
