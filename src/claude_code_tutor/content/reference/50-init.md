# /init

`/init` scans the repo and generates a starter `CLAUDE.md` capturing build/test
commands and conventions — the first thing to run in a new project so Claude knows
how to operate in it. What it writes *is* memory, so it's the front door to
[/memory](lesson:ref-memory), where you view and refine it over time.

**Related:** [/memory](lesson:ref-memory)
