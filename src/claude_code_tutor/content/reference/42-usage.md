# /usage

`/usage` (aliases `/cost`, `/stats`) shows what this session has spent — cost,
plan limits, and a breakdown of activity by tool, skill, subagent, and MCP
server. Use it to sanity-check spend on a long session or to see which subagents
and servers are doing the work. When the number surprises you, pair it with
[/context](lesson:ref-context) to see *where* the tokens are going.
