# /model

`/model [name]` switches the model for this session — a faster one for routine
edits, a more capable one for hard reasoning. Model choice drives both speed and
cost, so it pairs naturally with [/usage](lesson:ref-usage). It doesn't change
what's in your context, but a different model may use the
[/context](lesson:ref-context) window differently.
