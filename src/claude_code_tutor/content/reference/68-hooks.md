# /hooks

`/hooks` browses the hooks configured for this session — the shell commands that fire on lifecycle events (set in `settings.json`). Use it to confirm what automation is active. Closely related are [/permissions](lesson:ref-permissions) and [/mcp](lesson:ref-mcp).
