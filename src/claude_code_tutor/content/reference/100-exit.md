# /exit

`/exit` leaves the CLI cleanly — or detaches from a background session you're
attached to. The tidy way out versus a bare Ctrl+C. To end detached work rather
than leave, use [/stop](lesson:ref-stop).

**Related:** [/stop](lesson:ref-stop) · [/logout](lesson:ref-logout)
