# /status

`/status` reports your session essentials — Claude Code version, current model,
signed-in account, and connectivity (including MCP servers). Handily, it works
*while Claude is still responding*, so it's the quick "is everything wired up?"
glance when something feels off. For what the session is *costing*, jump to
[/usage](lesson:ref-usage).
