# /goal

`/goal [condition]` keeps Claude working across turns until a condition is met (or `clear` to drop it) — useful for objectives like *keep going until the tests pass*. It's the persistent cousin of [/loop](lesson:ref-loop); for a reviewed approach first, [/plan](lesson:ref-plan).

**Related:** [/loop](lesson:ref-loop) · [/plan](lesson:ref-plan)
