# /background

`/background` (alias `/bg`) detaches the current session to run as a background agent, freeing your terminal. Track detached work and bash tasks with [/tasks](lesson:ref-tasks); to repeat a prompt on a timer instead, [/loop](lesson:ref-loop).

**Related:** [/tasks](lesson:ref-tasks) · [/loop](lesson:ref-loop)
