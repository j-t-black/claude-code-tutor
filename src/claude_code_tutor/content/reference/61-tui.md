# /tui

`/tui [default|fullscreen]` switches the terminal renderer; **fullscreen** uses a flicker-free alt-screen with virtualised scrollback, nicer for long sessions. It pairs with [/theme](lesson:ref-theme) and [/statusline](lesson:ref-statusline) for the overall look.

**Related:** [/theme](lesson:ref-theme) · [/statusline](lesson:ref-statusline)
