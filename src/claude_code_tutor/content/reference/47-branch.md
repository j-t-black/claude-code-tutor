# /branch

`/branch [name]` forks the current conversation at this point — the original is
preserved, so you can try an alternative approach and switch back with
[/resume](lesson:ref-resume). Think of it as `git branch` for your chat: explore a
risky idea without losing the known-good thread. To step *backward* in place
rather than fork forward, use [/rewind](lesson:ref-rewind).

**Related:** [/resume](lesson:ref-resume) · [/rewind](lesson:ref-rewind)
