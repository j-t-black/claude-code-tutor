# /ultrareview

`/ultrareview [PR]` runs a deep, multi-agent review in the cloud — heavier and more thorough than a local pass (a few free runs, then credit-based). You trigger it yourself; it's the escalation when [/code-review](lesson:ref-code-review) isn't enough.
