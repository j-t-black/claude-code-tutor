# /sandbox

`/sandbox` toggles sandbox mode, which isolates command execution (filesystem and
network) for safety on supported platforms — so risky commands run boxed in. It
complements the rule-based control of [/permissions](lesson:ref-permissions).

**Related:** [/permissions](lesson:ref-permissions)
