# /doctor

`/doctor` health-checks your Claude Code install and settings, flagging problems with icons — press `f` to auto-fix what it can. First stop when something's misbehaving, before [/debug](lesson:ref-debug). For a lighter glance, [/status](lesson:ref-status).
