# /context

`/context` visualises how your context window is currently spent — system prompt,
tools/MCP, files, conversation, and memory. It's the diagnostic you run when a
session feels heavy or you're nearing the limit: see *what's* taking room, then
act. The usual follow-ups are [/compact](lesson:ref-compact) to summarise or
[/clear](lesson:ref-clear) to reset; [/usage](lesson:ref-usage) shows the cost
side of the same coin.
