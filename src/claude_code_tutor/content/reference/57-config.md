# /config

`/config` opens the Settings UI — theme, model, output style, editor (vim) mode — the interactive front end to your `settings.json`. For the individual knobs, see [/model](lesson:ref-model), [/theme](lesson:ref-theme), and [/effort](lesson:ref-effort).
