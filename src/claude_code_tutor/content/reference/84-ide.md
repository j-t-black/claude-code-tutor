# /ide

`/ide` manages IDE integrations (VS Code, JetBrains, and friends), linking Claude Code to your editor for richer context and diffs. For the standalone app, [/desktop](lesson:ref-desktop); to fix editor keybindings, [/terminal-setup](lesson:ref-terminal-setup).
