# /keybindings

`/keybindings` opens (or creates) your keybindings config file, where you can rebind keys and add chord shortcuts. It complements the quick fixes in [/terminal-setup](lesson:ref-terminal-setup) and the broader settings in [/config](lesson:ref-config).
