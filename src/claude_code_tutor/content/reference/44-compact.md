# /compact

`/compact` summarises the conversation so far into a compact form, freeing context
space while keeping the gist. Add a directive — `/compact focus: keep the auth
refactor` — to steer what survives. Reach for it on a long but *still-relevant*
session that's filling up; if the past no longer matters, [/clear](lesson:ref-clear)
is cleaner. Check the result with [/context](lesson:ref-context).

**Related:** [/context](lesson:ref-context) · [/clear](lesson:ref-clear)
