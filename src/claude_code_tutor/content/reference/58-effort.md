# /effort

`/effort [level]` sets how hard Claude thinks — low / medium / high / xhigh / max. More effort means deeper reasoning and slower, costlier turns, so dial it up for gnarly problems and down for routine edits. It sits alongside [/model](lesson:ref-model) in [/config](lesson:ref-config).
