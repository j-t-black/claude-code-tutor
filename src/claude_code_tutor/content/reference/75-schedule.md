# /schedule

`/schedule` (alias `/routines`) creates and manages **cloud** routines — cron jobs on Anthropic infrastructure that run independently of any terminal. It's how the tutor's own `/refresh-content` job stays automatic. For an in-session timer instead, [/loop](lesson:ref-loop).
