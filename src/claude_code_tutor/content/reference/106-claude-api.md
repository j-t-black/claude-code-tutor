# /claude-api

`/claude-api` loads Claude API / Managed Agents reference material into context —
and `/claude-api migrate` helps upgrade existing code to newer models. It's for
when you're building *with* the API rather than just using the CLI. Extend what
Claude can reach via [/mcp](lesson:ref-mcp) and [/skills](lesson:ref-skills).
