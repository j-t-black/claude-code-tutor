# /plugin

`/plugin` manages Claude Code plugins — bundles that add commands, skills, agents, or MCP servers. It's how you install and toggle third-party (or your own) extensions. See what they add via [/skills](lesson:ref-skills) and [/mcp](lesson:ref-mcp).
