# /memory

`/memory` opens every memory source for viewing and editing — the `CLAUDE.md`
hierarchy (user / project / local), imported rules, and the auto-memory Claude
maintains for itself. Good memory is half of good context: standing facts belong
here, not repeated in chat. Bootstrap a project's memory with
[/init](lesson:ref-init).
