# /terminal-setup

`/terminal-setup` configures terminal keybindings — most usefully Shift+Enter for newlines — so the input box behaves the way you expect. For the full keymap, [/keybindings](lesson:ref-keybindings); for editor links, [/ide](lesson:ref-ide).
