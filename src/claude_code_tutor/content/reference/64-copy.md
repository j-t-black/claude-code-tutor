# /copy

`/copy [N]` copies the last (or Nth-latest) assistant response to your clipboard — perfect for lifting a snippet or command out of the conversation. For the whole session, [/export](lesson:ref-export); to view changes, [/diff](lesson:ref-diff).

**Related:** [/export](lesson:ref-export) · [/diff](lesson:ref-diff)
