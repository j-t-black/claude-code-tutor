# /focus

`/focus` toggles focus view, which collapses the transcript to just your last
prompt and a one-line summary of each tool call — calmer and less noisy on long
sessions. A display sibling of [/tui](lesson:ref-tui).

**Related:** [/tui](lesson:ref-tui)
