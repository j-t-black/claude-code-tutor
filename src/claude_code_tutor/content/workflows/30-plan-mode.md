# Plan mode

Plan mode tells Claude to **research and propose before it touches anything**. It
reads the code, thinks through an approach, and presents a plan for your approval
— without making edits. You review, refine, and only then let it execute.

It's the right default for anything non-trivial or unfamiliar: you catch a wrong
approach while it's still cheap (a paragraph to fix) instead of after a pile of
edits. Pair it with the planning agents for larger designs.
