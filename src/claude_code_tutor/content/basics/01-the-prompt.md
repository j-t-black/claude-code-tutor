# The prompt & input box

The input box is where you talk to Claude Code. You describe a goal in plain
language; Claude works in **turns**, calling tools (reading files, running
commands, editing code) and reporting back.

A few fundamentals:

- **Enter** sends your message. Claude then works until the turn is done.
- **Esc** interrupts a running turn — useful when it's heading the wrong way.
- You can **queue** follow-up messages while a turn is in progress.
- Type **`/`** to open the slash-command menu, **`@`** to reference a file, and
  **`!`** to run a shell command inline.

The golden habit: give a clear goal and any constraints up front, then let Claude
execute. You can always interrupt and redirect.
