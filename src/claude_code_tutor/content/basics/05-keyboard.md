# Turns, interrupting & key shortcuts

Claude works in **turns**: you prompt, it responds with text and tool calls, you
reply. A few controls make that loop fast:

- **Esc** — interrupt the current turn (work done so far is kept).
- **Double Esc** — clear the input and stash it in history.
- **Enter** — send; you can **queue** more messages while a turn runs.
- **Ctrl+G** — open your prompt in an external editor for long, multi-line input.
- **Ctrl+O** — toggle the transcript viewer (see the detailed tool calls).
- **Ctrl+R** — search command history · **Up/Down** — recall previous prompts.
- **Ctrl+L** — redraw the screen · **Ctrl+C** — interrupt or exit.

You don't need to memorise these — but knowing Esc and Ctrl+O alone will change
how it feels to drive.
