# Pasting images

Claude Code is multimodal — you can paste an image straight from your clipboard
with **Ctrl+V** (use Ctrl+V even on macOS; the usual Cmd+V often won't paste into
the TUI). The image is referenced positionally in your prompt as `[Image #1]`,
`[Image #2]`, and so on.

Reach for it whenever a picture is faster than words: a UI mockup to build from, a
screenshot of an error dialog, a diagram to reproduce, or a chart to read. Claude
sees the image and the surrounding text together.
